# boatgoat
First attempt into designing a boat, end result was a little slow, I can't lie! 

If for some reson you would want to recreate this project, please find a better design! Issue was that it wasn't dense / heavy enough to fully submerge it, but I learned more about designing remote control boats for the future. 

Materials
- Metal drive dog shaft
- Brass inserts & M3 screws (to screw the motor to the base, and to screw both parts of the hull together)
- Water cooling jacket (size 36-L)
- Waterproof brushless motor (I used one with a 3670 label)
- Electronic speed controller (came with the brushless motor in a kit) 
- 4S Lipo battery, 14.8V

I wanted to experiment more with the impeller size since it would cost less than experimenting with different hulls, so there's a bunch of variations of impellers, including ones with different blade numbers and different angle of attack / pitches of the blade.
